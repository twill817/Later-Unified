# Color

Each swatch shows the light value, then the dark value. In code, use the CSS variable `--lo-color-<name>`, never the hex value.

## Contrast

Every text and status color meets WCAG AA (4.5:1) on the backgrounds it's used on, in both themes, and switch and benchmark states meet 3:1. Storybook checks this on every story: accessibility violations fail the story tests (`a11y: { test: 'error' }` in `.storybook/preview.tsx`).

- In dark mode the action color is a lighter purple, so primary buttons use dark text (`on-action`) rather than white.
- Group colors (publish, grow, creators) and status colors were darkened slightly in light mode so their text passes on the matching `-subtle` backgrounds.
- `text-tertiary` is the lightest gray allowed for text. Don't go lighter for captions or placeholders.
